# FiTabR: Feature-Weighted Retrieval for Tabular Deep Learning

FiTabR is a research project based on TabR (Tabular Deep Learning Meets Nearest Neighbors) with an extension that introduces feature-weighted retrieval mechanisms for improved similarity learning in tabular data.

## Overview

This project explores retrieval-augmented deep learning for tabular datasets, with a particular focus on:

- Feature-weighted similarity retrieval
- Medical tabular prediction tasks
- Improved contextual attention
- Ablation studies and benchmark evaluation

The implementation is built on top of the official TabR repository.
